
# Pig Game

A two-player dice game built with HTML, CSS, and Vanilla JavaScript. Players take turns rolling a dice, collecting points, and deciding when to hold their score. The first player to reach 100 points wins the game.

## Features

- **Two-Player Gameplay:** Take turns playing against another player.
- **Dice Rolling:** Generate random dice numbers from 1 to 6.
- **Score Tracking:** Keep track of both current and total scores.
- **Hold Score:** Save the current score and switch turns.
- **Turn Switching:** Automatically switch players when rolling a 1.
- **Winner Detection:** Declare the winner when a player reaches 100 points.
- **New Game:** Restart the game at any time.
- **Dynamic UI:** Update player states, scores, and game visuals dynamically.
